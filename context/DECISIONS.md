# Decisions register

Numbered, binding, append-only. Entry numbering is stable across sessions and
the corpus references entries as "decision N" — never renumber. Where an entry
overrides a plan, mark it as such; where a later entry supersedes an earlier
one, mark it inline (`SUPERSEDED by N`). This file itself stays `active`.

**Entry discipline:** a new entry records the ruling, the load-bearing
rationale, and one line per rejected alternative — target **30 lines or fewer**.
Measurements, tables, verbatim output, and correction records live in the
engagement's ledger or probe and are referenced, not embedded.
