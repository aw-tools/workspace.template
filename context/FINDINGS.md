# Findings

Durable, verified facts about the environment and tooling that a session should
not have to rediscover: platform and path quirks per machine, tool and toolchain
behaviour, git and remote specifics, module maps. Record what was verified and
how, not what was assumed. Rewrite entries in place when a fact changes; group
by topic as the file grows.
